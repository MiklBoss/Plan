# PLan
# Опора

Личный планировщик на русском: меньше переключений во время планирования, больше связи между большими целями и шагами сегодня.

## Запуск на компьютере

Нужен Node.js 20 или новее. Зависимости устанавливать не нужно.

```powershell
node server.mjs
```

Откройте http://localhost:5173. Для другого порта задайте переменную окружения `PORT`. На телефоне в той же домашней сети можно открыть `http://IP-адрес-компьютера:5173`, если брандмауэр разрешает подключение. Компьютер должен быть включён. Установка приложения и офлайн-режим на телефоне требуют HTTPS: для постоянного использования опубликуйте статические файлы на HTTPS-хостинге, например GitHub Pages. Публикация ещё не выполнена.

## Как пользоваться

- **Сегодня:** один фокус, горячие задачи, остальные дела, подзадачи, дата, оставшиеся дела и вечерний итог. Записи фокуса и итога сохраняются при вводе. Завершение родительской задачи завершает её подзадачи; повторное открытие задачи не сбрасывает уже сделанные подзадачи. Горячая подзадача выводит всю задачу в раздел горячих.
- **Стратегия:** направления на 1–10 лет. **Полугодие · квартал:** результаты промежуточного горизонта. **Месяц · неделя:** ближайшие планы. Период каждой цели задаётся текстом.
- **Проекты:** объединяют задачи и связываются с целями. В карточке цели открываются связанные цели и задачи. Продвижение цели отмечается вручную; оно не вычисляется автоматически по задачам.
- **Выгрузка мыслей:** входящие, «Когда-нибудь» и архив. Мысль можно превратить в задачу на выбранную дату. Исходная мысль остаётся в архиве.
- **Сосредоточиться:** скрывает навигацию, оставляет фокус, горячие задачи и таймер на 25 минут. Отвлекающую мысль можно записать, оставаясь в режиме фокуса. Таймер отсчитывает реальное время, в том числе после перезагрузки вкладки; завершение показывается при возвращении в приложение, фоновых уведомлений нет.
- **Настройки:** экспорт и импорт JSON, подключение GitHub. Импорт объединяет копию с текущими записями.
- Клавиши: `N` — задача, `I` — мысль, `F` — режим фокуса, `Esc` — выйти. Поддерживаются соответствующие клавиши русской раскладки.

Изначально пространство пустое. Кнопка «Посмотреть пример» добавляет редактируемые образцы всех горизонтов, проекта, задач и мысли. Это демонстрационные записи, отмеченные баннером. «Убрать пример» удаляет только добавленные образцы (включая изменения этих образцов); собственные отдельные записи остаются.

## Хранение и синхронизация

Планы сохраняются в `localStorage` этого браузера. Скачивайте резервные копии перед очисткой данных браузера или переходом на другой адрес приложения. Приложение работает без сервера данных, без аналитики и без внешних шрифтов или библиотек.

Для GitHub:

1. Создайте **закрытый репозиторий** с README. Он хранит личные планы, отдельно от публичного репозитория приложения.
2. Создайте fine-grained personal access token с доступом только к этому репозиторию и разрешением **Contents: Read and write**.
3. На каждом устройстве откройте настройки Опоры, укажите владельца, репозиторий, одинаковый путь к файлу (по умолчанию `opora-data.json`) и токен.
4. Нажимайте **«Синхронизировать» перед и после работы**. Синхронизация ручная; без подключения данные остаются локальными.

Токен хранится в `sessionStorage` вкладки, не включается в резервные копии и не записывается в репозиторий. Он отправляется только в API GitHub. Браузеры могут восстанавливать sessionStorage при восстановлении закрытой сессии. Хостинг и сторонние расширения должны быть доверенными.

Записи объединяются по ID и времени изменения. Независимые задачи с разных устройств сохраняются; более новая версия одной и той же записи побеждает целиком. При одновременном редактировании одной записи оба варианта текста не сохраняются. Удаления хранятся как отметки и не возвращаются при обычной синхронизации. Часы устройств должны быть выставлены корректно. Если файл изменился во время отправки, приложение получает свежую версию и повторяет объединение до трёх раз. Записи, изменённые локально во время запроса, сохраняются и отправляются при следующей синхронизации.

Используется [официальный GitHub Contents API](https://docs.github.com/en/rest/repos/contents?apiVersion=2022-11-28). Сервис Google для первой версии не требуется.

## Публикация

Разместите `index.html`, `styles.css`, `app.js`, `core.js`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png` и `manifest.webmanifest` на статическом HTTPS-хостинге. Все пути относительные, поэтому приложение поддерживает адреса вида `https://username.github.io/opora/`. Публикация на GitHub Pages и создание репозитория здесь не выполнялись.

После первого успешного открытия по HTTPS или на localhost service worker сохраняет интерфейс для работы без интернета. Возможность установки зависит от браузера; на iPhone используйте Safari → «На экран Домой». Синхронизации нужен интернет. На телефоне и ПК используйте один опубликованный адрес приложения.

## Проверка

```powershell
node --test tests/core.test.mjs
```

Проверяются объединение данных разных устройств, более новые изменения, удаления, Unicode, проверка резервных копий и переходы между датами. Для браузерной проверки запустите приложение, установите Playwright и выполните `node tests/browser.mjs`. При использовании готовой установки задайте `OPORA_PLAYWRIGHT` — путь к `playwright/index.mjs`, при необходимости `OPORA_BROWSER` — путь к Chromium/Chrome. Проверка работает в отдельном временном профиле, не затрагивая планы пользователя; GitHub API заменяется тестовым сервером. Проверяются интерфейс, подзадачи, сохранение, связи, конфликт синхронизации, экспорт, мобильная ширина и офлайн-перезагрузка. Скриншоты сохраняются в `artifacts/`.
